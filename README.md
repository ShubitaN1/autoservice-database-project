# ავტოსერვისის მართვის რელაციური მონაცემთა ბაზა

## პროექტის აღწერა

პროექტი წარმოადგენს ავტოსერვისის მართვის რელაციურ მონაცემთა ბაზას, რომელიც შექმნილია MySQL პლატფორმაზე. სისტემის მიზანია ავტოსერვისის ყოველდღიური საქმიანობის ეფექტურად მართვა, მომხმარებლების, ავტომობილების, სერვისების, სამუშაო შეკვეთების, გადახდებისა და სათადარიგო ნაწილების შესახებ ინფორმაციის ცენტრალიზებული შენახვისა და დამუშავების გზით.

## პროექტის მიზანი

პროექტის მთავარი მიზანია ავტოსერვისში მიმდინარე პროცესების ავტომატიზაცია და მონაცემების ორგანიზებული მართვა. სისტემა უზრუნველყოფს:

* მომხმარებლების მონაცემების შენახვას;
* ავტომობილების აღრიცხვას;
* სერვისების მართვას;
* სამუშაო შეკვეთების კონტროლს;
* გადახდების აღრიცხვას;
* სათადარიგო ნაწილების მართვას;
* ანგარიშგებისა და ანალიზისთვის საჭირო ინფორმაციის მიღებას.

## გამოყენებული ტექნოლოგიები

* MySQL Server 8.0
* MySQL Workbench
* SQL (DDL, DML, DCL)

## მონაცემთა ბაზის ძირითადი ობიექტები

სისტემა მოიცავს შემდეგ ძირითად ცხრილებს:

* Customers (მომხმარებლები)
* Vehicles (ავტომობილები)
* Services (სერვისები)
* Employees (თანამშრომლები)
* Work_Orders (სამუშაო შეკვეთები)
* Payments (გადახდები)
* Spare_Parts (სათადარიგო ნაწილები)

## დამატებითი ფუნქციონალი

პროექტში გამოყენებულია:

### Views

* vw_service_report
* vw_payment_report

### Stored Procedures

* GetCustomerServiceHistory

### Triggers

* trg_update_order_status_after_payment

## ინსტალაციის ინსტრუქცია

1. დააინსტალირეთ MySQL Server.
2. დააინსტალირეთ MySQL Workbench.
3. გახსენით `autoservice_database_final.sql` ფაილი MySQL Workbench-ში.
4. გაუშვით SQL სკრიპტი (Execute).
5. მონაცემთა ბაზა ავტომატურად შეიქმნება და შეივსება სატესტო მონაცემებით.

## სისტემის გამოყენება

მომხმარებელს შეუძლია SQL მოთხოვნების გამოყენებით:

* მომხმარებლების სიის ნახვა;
* ავტომობილების მონაცემების მოძიება;
* სამუშაო შეკვეთების მართვა;
* გადახდების კონტროლი;
* სერვისების ისტორიის მიღება;
* ანგარიშების გენერირება.

## EER დიაგრამა

პროექტს თან ერთვის EER (Enhanced Entity Relationship) დიაგრამა, რომელიც ასახავს მონაცემთა ბაზის სტრუქტურასა და ცხრილებს შორის კავშირებს.
